# Run-cél, ajánlott D3, menedzsment-célkitűzések — 1.0.4.13.00

Kimondott kérés: *„A ligalépcsős módban annyira jelentősen megváltozott már minden, hogy a
D6-ból D1-be feljutni gyakorlatilag egy élet… legyen az, hogy a Run szintet mindig úgy kapja
meg a játékos, hogy a választott kezdő divíziótól kettővel feljebbi szinten, ha tud
bajnokságot nyerni, akkor megvan a Run szint. Onnan már szabad pálya, hogy addig játszik,
amíg akar. A számításon nem kell változtatni. Plusz legyen az ajánlott kezdő szint mindig a
D3. A karrier kezdésénél legyen egy ilyen menedzsment célkitűzések ablak … nyerd meg ezt és
ezt a divíziót. Azt, ami 2-vel feljebb van, és a neve legyen, ne az, hogy D1 vagy D3."*

## 1. A Run-cél
- **Cél = a kezdő osztálynál kettővel feljebbi bajnokság** (`pyrRunGoalDivFor`):
  D6 → D4, D5 → D3, D4 → D2, D3/D2/D1 → élvonal.
- Az első olyan bajnoki cím, ami a cél osztályában **vagy feljebb** születik (a kihirdetés
  pillanatában, `runNotePyrGoal`):
  - a Run felkerül a helyi Run-ranglistára (és feltöltődik, ha az online lista él);
  - jön a futás záróképernyője;
  - a napló kimondja: „a Run szinted megvan, innentől szabad pálya".
- Utána a köztes osztályok címe már nem hoz újabb záróképernyőt; az élvonalbeli címek (a
  régi szabály szerint) igen.
- **A Run számítása változatlan**: plafon × teljesítmény, a tempó-tétel továbbra is az első
  élvonalbeli címhez mér (`R.pyrTitleSeason` érintetlen). A ranglista a cél pillanatának
  Run-szintjét rögzíti.
- Futó karrierekre is él: ha a napló szerint a cél címe már megvolt, a ranglista-őr
  (`runBoardEnsure`) utólag felveszi.

## 2. Ajánlott kezdő szint: D3
- `pyrRecommendDiv` mindig a D3-at adja (zárt osztályra nem eshet). Az osztályválasztóban
  a D3 sora „⭐ AJÁNLOTT", és minden sor kiírja a saját Run-célját a liga nevével.

## 3. Menedzsment-célkitűzések
- A karrier indításakor (osztályválasztás után) felugró ablak: „Az elnökség elvárásai…" —
  **„🏆 Nyerd meg: ‹a cél liga neve›"**, a kezdő liga nevével és egy rövid magyarázattal;
  folyamatban / ✓ teljesítve (idény).
- A HUB-on, a Run-mérő alatt egy sor („📋 Célkitűzés: …") újranyitja.
- Bővíthető: a célok az állapotból származnak (`mgmtGoals()`), új cél = új bejegyzés,
  migráció nélkül; a mentés csak azt viszi, hogy az ablak megvolt (`S.mgmtSeen`).
